# joule-lang

Joule — self-hosted energy-aware programming language

Free-to-use binaries and examples (BSL-1.1). Private source mirror at
[openIE-dev/joule-lang-core](https://github.com/openIE-dev/joule-lang-core).

## Quick start

```bash
# Examples live in ./examples
ls examples/
```

## Distribution

Binary releases will land on the Releases page as each component
reaches v0.1.0. The compiler is currently in alpha; tracking progress
at openIE-dev.
