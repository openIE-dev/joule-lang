Module ndarray_emit 

Source
Expand description

C code emission for N-dimensional array types.

Generates C struct typedefs, constructors, element access, view creation, and destructor functions for NDArray, NDView, CowArray, and DynArray.

Layout:

  • NDArray: owned contiguous data + inline shape/strides (rank baked into type)
  • NDView: borrowed pointer + offset (zero-copy view into NDArray)
  • CowArray: refcounted shared data (clone-on-write)
  • DynArray: heap-allocated shape/strides (rank determined at runtime)
