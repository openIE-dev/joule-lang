Monomorphization for Joule

Converts generic code to specialized versions for each concrete type instantiation. This module handles:

  • Collecting all generic instantiations from the program
  • Generating specialized versions of generic functions and types
  • Name mangling for different instantiations
  • Integration with MIR generation
