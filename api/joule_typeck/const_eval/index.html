Compile-time constant evaluation for Joule’s const fn and comptime {} features.

This module implements a HIR-level interpreter that evaluates expressions at compile time. It supports arithmetic, boolean logic, comparisons, string operations, if/else, let bindings, and calls to other const fn functions (with a recursion depth limit).
