Type checker and name resolution for Joule

This module implements:

  • Name resolution (mapping identifiers to definitions)
  • Type checking (verifying type correctness)
  • Type inference (deducing types from context)
  • HIR lowering (converting typed AST to HIR)
  • Energy budget analysis and compile-time estimation
  • Generic type instantiation and monomorphization
  • Trait resolution and method lookup
