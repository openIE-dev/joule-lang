Standard library module registry

Maps use std::module imports to builtin function signatures. When a user writes use std::math::*, the typechecker registers all known math functions into the current scope.

This approach avoids parsing the stdlib .joule files (which use features like extern "intrinsic" and unsafe {}) and instead provides verified function signatures directly.

The C codegen maps these function names to their libc/libm implementations or inline C helper functions in the prelude.
