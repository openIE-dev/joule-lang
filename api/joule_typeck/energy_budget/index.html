Compile-time Energy Budget Estimation

This module implements static analysis for estimating energy consumption of HIR functions. It uses the energy cost model from joule-energy to compute approximate energy costs based on the operations in the code.

§Key Features

  • Walks HIR expressions and accumulates energy costs
  • Handles loops with configurable iteration bounds
  • Tracks confidence levels for estimates (lower for unbounded loops)
  • Compares estimates against declared budgets

§Example

ⓘ
use joule_typeck::EnergyEstimator;
use joule_hir::Function;

let estimator = EnergyEstimator::default();
let estimate = estimator.estimate_function(&func);

if let Some(violation) = estimator.check_budget(&func) {
    println!("warning: {}", violation.message);
}
