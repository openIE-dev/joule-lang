Backend Orchestrator for Joule Compiler

This crate provides unified access to all Joule codegen backends:

  • Cranelift: Fast compilation for debug builds
  • LLVM: Optimized compilation for release builds
  • MLIR: Heterogeneous computing (GPU, accelerators)

§Backend Selection

The orchestrator can automatically select the best backend based on:

  • Build profile (debug vs release)
  • Target architecture
  • Code characteristics (contains GPU kernels, etc.)
  • User preferences (–backend flag)

§Hybrid Compilation

For programs with mixed CPU and GPU code, the hybrid compiler can:

  • Analyze MIR to detect GPU-annotated functions
  • Split code into CPU and GPU modules
  • Compile each with the appropriate backend
  • Link the results into a unified executable

See the hybrid module for more details.

§Example

ⓘ
use joule_codegen::{Orchestrator, Backend, CompileOptions};

let orchestrator = Orchestrator::new();

// Auto-select backend
let result = orchestrator.compile(&mir_context, CompileOptions::default())?;

// Or specify backend explicitly
let result = orchestrator.compile_with_backend(
    &mir_context,
    Backend::Llvm,
    CompileOptions::release(),
)?;

// For hybrid CPU/GPU compilation
use joule_codegen::hybrid::{HybridCompiler, HybridTarget};
let hybrid = HybridCompiler::new(HybridTarget::Cuda);
let result = hybrid.compile_hybrid(&mir_context, 2)?;
