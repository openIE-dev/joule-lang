Hybrid compiler for mixed CPU/GPU code.

The hybrid compiler analyzes MIR to detect GPU-annotated functions, splits the code into CPU and GPU modules, compiles each with the appropriate backend, and links the results together.

§GPU Detection

Functions are identified as GPU kernels if they:

  • Have a name containing “gpu” or “kernel”
  • Are annotated with #[gpu] attribute (when attribute support is added)
  • Are called from within a GPU context

§Backend Selection

  • CPU code is compiled with Cranelift (fast) or LLVM (optimized)
  • GPU code is compiled with MLIR, which lowers to the target platform

pub fn analyze_targets(&self, mir: &MirContext) -> TargetAnalysis

Analyze the MIR to determine which targets are needed.

This examines all functions in the MIR and categorizes them as:

  • CPU functions: Regular functions compiled for the host
  • GPU functions: Kernels that run on the GPU
  • Host helpers: Functions called from GPU but run on CPU
§GPU Detection Heuristics

Currently uses simple name-based detection:

  • Functions with “gpu” or “kernel” in their name are GPU functions
  • All other functions are CPU functions

In the future, this will be extended to check for:

  • #[gpu] attributes
  • Parallel loop annotations
  • GPU intrinsic calls

pub fn compile_hybrid( &self, mir: &MirContext, opt_level: u8, ) -> CodegenResult<HybridCompileResult>

Perform hybrid compilation of the MIR.

This splits the MIR into CPU and GPU modules, compiles each with the appropriate backend, and returns the object code for both.

§Arguments
  • mir - The MIR context to compile
  • opt_level - Optimization level (0-3)
§Errors

Returns an error if compilation fails for either target.

pub fn link_hybrid( &self, cpu_object: &[u8], gpu_object: Option<&[u8]>, ) -> CodegenResult<Vec<u8>>

Link CPU and GPU objects into a unified executable.

This combines the CPU object code with GPU device code, setting up runtime linking for GPU kernel dispatch.

§Arguments
  • cpu_object - Compiled CPU object code
  • gpu_object - Optional compiled GPU object code
§Returns

Combined object code ready for final linking with the system linker.
