Hybrid Compilation Support

This module provides support for hybrid compilation, where code is split between CPU and GPU targets and compiled with appropriate backends.

§Architecture

The hybrid compiler works in three phases:

  1. Analysis: Examine MIR to identify GPU-annotated functions and determine which backends are needed for each function.

  2. Compilation: Split the MIR into CPU and GPU modules, then compile each with the appropriate backend (Cranelift/LLVM for CPU, MLIR for GPU).

  3. Linking: Combine the CPU and GPU object files into a unified executable with runtime linking support for GPU kernels.

§Example

ⓘ
use joule_codegen::hybrid::{HybridCompiler, HybridTarget};

let compiler = HybridCompiler::new(HybridTarget::Cuda);

// Analyze the MIR to determine targets
let targets = compiler.analyze_targets(&mir);

if targets.needs_gpu {
    // Perform hybrid compilation
    let result = compiler.compile_hybrid(&mir, 2)?;
    let linked = compiler.link_hybrid(&result.cpu_object, result.gpu_object.as_deref())?;
}
