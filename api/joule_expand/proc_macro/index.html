Procedural macro types for Joule

This module defines the TokenStream/TokenTree types used by the proc macro system. These types serve as the bridge between Joule source tokens and macro expansion.

Architecture:

  • Rust-side types (TokenTree, TokenStream): used within the compiler
  • C-ABI types (CTokenTree, CTokenStream): used across dylib boundaries (Session 44)
  • Conversion functions: SpannedToken <-> TokenTree
