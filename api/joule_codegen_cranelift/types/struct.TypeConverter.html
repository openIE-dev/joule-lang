pub fn convert_type(&self, ty: &Ty) -> Option<Type>

Convert a MIR type to a Cranelift scalar type.

Returns None for zero-sized types (Unit, Never). Composite types (structs, multi-element tuples, enums) return the pointer type because they live in stack slots and are referenced by address.
