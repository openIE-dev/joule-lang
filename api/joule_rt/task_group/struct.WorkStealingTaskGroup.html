Struct WorkStealingTaskGroup 

Source 
pub struct WorkStealingTaskGroup { /* private fields */ }
Expand description

A task group that uses the work-stealing executor.

This is the recommended task group for production use as it efficiently distributes work across multiple threads.

§Example

ⓘ
let group = WorkStealingTaskGroup::new();

group.spawn(async {
    // Task 1 runs on work-stealing executor
});

group.spawn(async {
    // Task 2 runs on work-stealing executor
});

// Wait for all tasks
group.join().await;
