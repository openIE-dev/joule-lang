Struct WorkStealingExecutor 

Source 
pub struct WorkStealingExecutor { /* private fields */ }
Expand description

A multi-threaded work-stealing executor.

This executor distributes work across multiple worker threads, with idle workers stealing from busy ones to maintain balance.

§Example

ⓘ
let executor = WorkStealingExecutor::new(4); // 4 worker threads

executor.spawn(async {
    println!("Hello from work-stealing executor!");
});

executor.run();
