Function timeout

pub fn timeout<F: Future>(duration: Duration, future: F) -> Timeout<F> ⓘ
Expand description

Run a future with a timeout.

If the future does not complete within the specified duration, returns Err(TimeoutError).

§Example

ⓘ
match timeout(Duration::from_secs(5), fetch_data()).await {
    Ok(data) => println!("Got data: {:?}", data),
    Err(_) => println!("Request timed out"),
}
