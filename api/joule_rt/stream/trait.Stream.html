Expand description

A stream of values produced asynchronously.

This is the async equivalent of Iterator.

Required Associated Types§

Source

type Item

The type of items yielded by the stream.

Required Methods§

Source

fn poll_next( self: Pin<&mut Self>, cx: &mut Context<'_>, ) -> Poll<Option<Self::Item>>

Attempt to pull out the next value of this stream.

Returns Poll::Ready(Some(item)) if an item is ready, Poll::Ready(None) if the stream is exhausted, or Poll::Pending if the next item is not yet available.
