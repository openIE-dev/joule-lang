Async streams (async iterators) for Joule runtime

This module provides a Stream trait similar to Rust’s futures::Stream, along with common combinators and adapters.

§Example

ⓘ
use joule_rt::stream::{Stream, StreamExt, iter};

let mut stream = iter([1, 2, 3, 4, 5])
    .map(|x| x * 2)
    .filter(|x| *x > 4);

while let Some(value) = stream.next().await {
    println!("{}", value);
}
