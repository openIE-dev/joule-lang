Borrow checker for Joule

This module implements ownership and borrowing analysis using NLL (Non-Lexical Lifetimes).

§Features

  • Use-after-move detection: Catches use of values after they’ve been moved
  • Use-of-uninitialized detection: Ensures variables are initialized before use
  • Mutability checking: Prevents mutable borrows during existing borrows
  • Lifetime tracking: Region-based lifetime analysis for references
  • Borrow conflict detection: Detects conflicting borrows (multiple mutable, mixed mut/shared)

§Lifetime Model

Joule uses a region-based lifetime system similar to Rust’s NLL:

  • Each reference has an associated lifetime region
  • Regions are sets of program points where the borrow is active
  • Borrows must not outlive the borrowed data
  • Multiple shared borrows are allowed, but mutable borrows are exclusive
