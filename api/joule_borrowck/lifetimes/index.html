Lifetime tracking for Joule borrow checker

This module implements lifetime analysis for references:

  • Lifetime regions (tracking when borrows are active)
  • Loan tracking (what is borrowed and for how long)
  • Constraint generation and solving
  • Non-lexical lifetimes (NLL) support

§Lifetime Model

Joule uses a region-based lifetime system similar to Rust’s NLL:

  • Each reference has an associated lifetime region
  • Regions are sets of program points where the borrow is active
  • Borrows must not outlive the borrowed data

§Example

fn example() {
    let x = 42;      // x created at point P0
    let r = &x;      // r borrows x, lifetime 'a starts at P1
    println!("{}", r); // r used at P2, 'a must include P1..P2
}                    // x dropped at P3, 'a must end before P3
